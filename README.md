# Varoluşsal Çay Kazanı

> Bu belge, TentiAŞ Çay ve Ontoloji Müdürlüğü tarafından **29 Eylül 2026** tarihinde mühürlenmiştir.

## Ne işe yarar?

Hiçbir şeye. Ama çok ciddi bir hiçbir şeye.

`varolussal-cay-kazani`, suyun 100°C'ye ulaşmasını beklerken sizin varoluşunuzu da kaynatmayı amaçlayan resmi bir protokoldür. Kazan çalışır. Çay demlenir. Siz hâlâ aynı kişi misiniz, o kısım garanti dışıdır.

## Kurulum

```bash
python3 kazan.py
```

Bağımlılık: Python 3 ve biraz sabır. Çay yaprakları isteğe bağlıdır; yazılım zaten felsefi olarak demlenmiştir.

## Kullanım senaryoları

1. Sabah 07:12. Evren henüz ısınmamış.
2. Kazanı çalıştır.
3. Ekrandaki uyarıları oku. İçlerinden birini ciddiye alma.
4. Çay hazır yazısını görünce bardağı doldur. Bardağın varlığı kullanıcı sorumluluğundundadır.
